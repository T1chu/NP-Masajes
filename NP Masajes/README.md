# NP Masajes — sitio web

## Estructura
- `index.html` — página principal (servicios, filosofía, galería, contacto)
- `admin.html` — panel para editar precios
- `css/styles.css` — estilos
- `js/main.js` — lógica del sitio (precios dinámicos, galería, menú)
- `js/admin.js` — lógica del panel admin
- `images/` — fotos de la galería (ver `images/LEEME.txt`)

## Cómo ver el sitio
Hacé doble clic en `index.html` para abrirlo en el navegador.

## Panel administrador
Entrá desde el link "Panel administrador" al pie de la página, o abriendo
`admin.html` directamente.

- **Usuario:** Noelia
- **Contraseña:** Narita123

Desde ahí se pueden modificar los precios de los 5 servicios. Al guardar,
los precios se actualizan automáticamente en `index.html`.

> Importante: para que los precios guardados en el panel se reflejen en la
> página principal, ambos archivos tienen que abrirse desde el mismo
> navegador (los cambios quedan guardados en ese navegador, no en un
> servidor). Si notás que el precio no cambia al abrir `index.html` con
> doble clic, probá abrir la carpeta con un servidor local simple (por
> ejemplo, con la extensión "Live Server" de VS Code) — con algunos
> navegadores, abrir archivos sueltos con doble clic restringe el
> guardado local entre páginas distintas.
